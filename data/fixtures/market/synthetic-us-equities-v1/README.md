# Synthetic US equities fixture v1

> **SYNTHETIC FIXTURE. NOT MARKET DATA.** Every instrument, price, volume and event in this directory was generated by `aura.data.fixture_generator` from a fixed seed. None of it describes a real security, company, exchange or market. Do not treat it as evidence about markets, strategies or models, and never use it as qualification evidence. The provenance class is `SYNTHETIC_FIXTURE` and `manifest.json` declares `not_market_data: true`.

The decision and its limits are recorded in [ADR-0024](../../../../docs/adr/0024-synthetic-fixture-market-data.md).

## Regenerate and verify

```powershell
uv run python -m aura.data.fixture_generator --out data/fixtures/market/synthetic-us-equities-v1
uv run pytest tests/test_fixture_dataset.py
```

Regeneration is byte-identical. The generator uses integer SplitMix64 draws (seed 20260923), `Decimal` arithmetic under a pinned context, LF line endings and float-free formatting. `.gitattributes` turns off line-ending conversion under `data/fixtures/`. The tests regenerate the dataset into a temporary folder and compare SHA-256 hashes with these files and with `manifest.json`. Any change to the generated bytes needs a new dataset version in a new directory; v1 is immutable.

## Time semantics

- Instants are UTC in RFC 3339 form with a `Z` suffix. Dates are America/New_York session dates.
- A daily bar covers 09:30 to 16:00 America/New_York. `interval_start` and `interval_end` store those instants in UTC, so they move by an hour across daylight-saving changes: 14:30Z to 21:00Z under EST, 13:30Z to 20:00Z under EDT. The window crosses the changes on 2024-03-10, 2024-11-03 and 2025-03-09.
- `interval_end` is the bar's event time. `available_at` is `interval_end` plus the declared 15-minute publication delay unless a scenario says otherwise. Point-in-time readers must require `event_time <= as_of` and `available_at <= knowledge_cutoff`.
- Reference records carry their own `available_at`: 08:00 New York for records known before trading, 17:00 New York for notices published after the close. `universe_membership.csv` is an append-only event log: a row takes effect from its `effective_from` and is known from its `available_at`.
- `symbol_history.csv` periods run from `effective_from` (inclusive) to `effective_to` (exclusive, empty while open) and never overlap. The end of a period becomes known with the `available_at` of the row that replaces it, so resolve symbols with `as_of <= knowledge_cutoff`.
- `bars_1d.csv` rows are in delivery order, which never decreases in `available_at`. Delivery order is not event order. `provider_record_id` plus `revision` identifies an observation.
- Prices are unadjusted USD on a $0.01 tick with exactly two decimal places. Volume is an integer number of shares.

## Calendar `FIXTURE_WEEKDAY_V1`

Weekdays from 2024-01-02 to 2025-07-08 minus the declared fixture holidays, 380 sessions in all. **This is not an exchange calendar.** It has no early closes, no unscheduled closures and no exchange rules; every session runs 09:30 to 16:00 New York time. Fixture holidays: 2024-01-15, 2024-02-19, 2024-03-29, 2024-05-27, 2024-06-19, 2024-07-04, 2024-09-02, 2024-11-28, 2024-12-25, 2025-01-01, 2025-01-20, 2025-02-17, 2025-04-18, 2025-05-26, 2025-06-19, 2025-07-04.

A 200-session warm-up is complete on 2024-10-16 for instruments that cover the whole window.

## Price process

A seeded regime-switching random walk. Each session's market return is `drift + volatility * z`; range-bound segments also pull the market level back toward its level at the start of the segment. An instrument's return is beta times the market return plus a fictional-sector factor and idiosyncratic noise. `z` is an Irwin-Hall approximation to a standard normal: twelve 53-bit uniforms minus 6. Open, high and low come from seeded gap and range draws. High rounds up and low rounds down to the tick, so every generated bar keeps `low <= open, close <= high`.

The segments below are generator parameters for tests. They are **not** regime classifications and must not be used as labels for the Regime Engine. Drift and volatility are the daily market-factor parameters.
